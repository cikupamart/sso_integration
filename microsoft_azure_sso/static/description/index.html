Microsoft Azure SSO Integration

Let your team sign in to Odoo with the Microsoft account they already use every day. One click, no new password, full visibility into every login attempt.

🔐

Microsoft Single Sign-On

A "Login with Microsoft" button appears right on the Odoo login page. Authentication runs on the standard OAuth2 / Azure AD (Entra ID) flow.

🔑

No New Credentials

Users authenticate with the Microsoft account they already know. Nothing new to remember, nothing new to reset.

🔔

Login Notifications

Users get an instant confirmation when they sign in successfully. Administrators are emailed automatically whenever a login attempt fails.

📋

Audit Logs & Tracking

Every login attempt — successful or failed — is recorded with timestamp, Microsoft account, matched Odoo user, IP address, and error details.

📊

SSO Dashboard

An at-a-glance dashboard shows total logins, success/failure counts, unique users, and the most recent sign-in activity.

⚙️

Simple Configuration

Everything is configured from Settings → General Settings: Client ID, Client Secret, Tenant ID, auto-create users, and notification toggles.

Track every login at a glance

How It Works

1
Register an app in Azure Portal and copy the Client ID, Secret and Tenant ID.
2
Paste the credentials into Odoo Settings and enable Microsoft SSO.
3
Users click "Login with Microsoft" on the login page and sign in normally.
4
Track every attempt in the Dashboard and Audit Logs.

Compatible with Odoo 18.0 • Requires an Azure Active Directory (Entra ID) App Registration

A built-in "Panduan Penggunaan" (usage guide) is available inside the module under the Microsoft SSO menu.
